# 📱 PageSim

**PageSim** is a visual simulation app designed to help students understand **Operating System (OS)** concepts—specifically **page replacement algorithms**.

It provides an interactive way to learn how different algorithms manage memory and handle page faults.

---

## 🚀 Features

- 📊 Visual simulation of page replacement algorithms  
- ⚡ Step-by-step execution  
- 🎓 Educational explanations for each algorithm  
- 🧠 Helps understand memory management concepts  

---

## 🧮 Supported Algorithms

The app currently supports:

- **First In First Out (FIFO)**  
- **Least Recently Used (LRU)**  
- **Optimal Page Replacement Algorithm**

### 🛠 Requirements

Make sure you have:

- Android Studio or Gradle  
- Git installed on your system  

---

### 📥 Setup Instructions

#### 1. Clone the repository

```
git clone https://github.com/vishwajithkv/PageSim.git -b v1.0.0
```

#### 2. Navigate into the project

```
cd PageSim
```

#### 3. Build & Run

**Using Gradle:**
```
./gradlew build
```

**Using Android Studio:**
- Open the project  
- Click **Run ▶️**
